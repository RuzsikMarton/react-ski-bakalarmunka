# 🎿 React Ski – Bachelor Thesis Project

A full-stack ski platform built with **React** and **Node.js/Express** as part of a bachelor’s thesis.  
The app features authentication, user interaction, and ski-related data visualization with a modern UI.  
---

## 🚀 Tech Stack

### Frontend
- React 18 (CRA)
- React Router DOM 6
- Ant Design (UI components)
- Bootstrap / React-Bootstrap
- Axios (API requests)
- React Toastify (notifications)
- React Google Charts (charts & statistics)
- React Helmet Async (SEO)
- Moment.js (date/time handling)


   ### Backend
- Node.js + Express
- MongoDB + Mongoose
- JWT (authentication & authorization)
- bcryptjs (password hashing)
- Multer + Cloudinary (file uploads)
- dotenv (environment config)
- express-async-handler (async error handling)
- nodemon (dev server)

---

## ✨ Features
- **Authentication**: Secure login & registration with JWT and bcrypt  
- **User Profiles**: Manage user data, and settings  
- **Charts & Analytics**: Visualize ski data with Google Charts  
- **Image Uploads**: Upload rental/resort images via Multer & Cloudinary  
- **Responsive UI**: Styled with Ant Design + Bootstrap
- **API Integration**: Axios-based data fetching with toast notifications  
- **Error Handling**: Async middleware + user-friendly error messages
